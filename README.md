# Simple Bank System (C++)

A console-based banking application written in C++ that allows users to log in, check their balance, deposit funds, and withdraw money, with data persistence using text files.

## Features

* **User Login:** Authenticates existing users from a local data file (`bank_data.txt`).
* **Deposit Funds:** Add money to your account balance.
* **Withdraw Funds:** Securely withdraw money with balance validation.
* **Balance Inquiry:** Check your current account balance.
* **Interactive Menu:** Clean console UI with operational loops.

## Technologies Used

* **Language:** C++ (Standard C++11 or higher)
* **File I/O:** `<fstream>` for reading and writing user data.
